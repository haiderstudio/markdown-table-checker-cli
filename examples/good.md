# A doc with good tables

| Name | Price |
| --- | ---: |
| Apples | 2 |
| Oranges | 3 |

A table without outer pipes:

Name | Price
--- | ---:
Apples | 2

A table with an escaped pipe in a cell:

| Item | Note |
| --- | --- |
| Pipe | a \| b |

A one-column table:

| Item |
| --- |
| Only |

A line with a pipe in prose is not a table: use a | b when you mean or.
